# Simulation d’un service réseau connecté

Simulation de primitives de connexion, transfert et déconnexion entre entités transport et réseau.

## Technologies

Java, threads, fichiers, modèle OSI simplifié.

## Installation et utilisation

Avec un JDK : `javac -encoding UTF-8 -d build MainSimulation.java`, puis `java -cp build MainSimulation`. Examiner les fichiers d’entrée avant lancement ; les boucles peuvent tourner en continu.

## État et limites

Les fichiers simulent les échanges ; il ne s’agit pas d’une implémentation réseau réelle. Les entrées fournies ne garantissent pas une démonstration complète.

Préparation du dépôt : nettoyage des fichiers générés et ajout de cette documentation. Aucun test fonctionnel de bout en bout n’a encore été effectué ; les commandes ci-dessus sont des indications dérivées des sources, pas une certification de fonctionnement.
